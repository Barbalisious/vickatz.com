קובץ `supabase_schema_v1.sql` כולל:
- `conversations` — שיחה = מספר טלפון + חלון זמן, ענף, סטטוס, ספירת חילופים.

- `message_log` — לוג גולמי ל-rate-limiting וספירת "שיחה אחת ליום".
- Views: `leads_dashboard`, `daily_usage` (לשימוש כדשבורד בעורך הטבלאות).

### קוד שרת — שלד ראשוני
תיקיית `bot_server/` כוללת שרת FastAPI עובד (נבדק syntactically):
- `app/main.py` — endpoint webhook (GET לאימות, POST לקבלת הודעות),
  עם כל זרימת ההגנות לפני קריאה ל-Claude.
- `app/guardrails.py` — בדיקת rate-limit ובדיקת מכסת שיחה יומית.
- `app/db.py` — עטיפת Supabase לפי הסכימה.
- `app/claude_client.py` — קריאה ל-Claude (מודל זול/מהיר, max_tokens נמוך).
- `app/whatsapp.py` — שליחת הודעות דרך WhatsApp Cloud API.
- `requirements.txt`, `.env.example`, `README.md` עם הוראות הרצה.
